Architecture Specifications

Hierarchy Setup & Entity-Relationship Model

1. Logical Setup Hierarchy Model (Physical Floor to Digital Code)

To ensure high-fidelity data tracking, physical units are mapped into digital endpoints according to the following top-down constraints:

Level 1

Line Groups

Collections of production lines grouped by division, floor building, product category, or dedicated supervisors.

Level 2

Production Lines

Standardizes layouts either as Traditional Sequential rows or Modular Cell Loops with distinct SAM efficiency configurations.

Level 3

Workstations

Logical sequential points of assembly. Binds tablet interaction frameworks (Fixed-Mount, Floating, Shared Cell options).

Level 4

Machine Registry

The physical sewing assets pool (DDL-9000 Lockstitch, Overlocks). Dynamically bound or statically mapped to Workstation nodes.

Real-Time Data

Production Logs

Automated "+1 Good Piece" or "Rework" event captures from Operator tablet interfaces, triggering real-time efficiency dashboards.

Local Sync Architecture

In this POC, the database schemas are simulated in memory and continuously serialized into the browser's localStorage database under standard JSON blocks. In a full production deployment, the relationship mappings are managed via relational relational databases (e.g., PostgreSQL or Firestore) utilizing cascade triggers upon deletion of a parent entity.

Cardinality & Cascades

Under traditional layouts, the mapping between WORKSTATION and MACHINE_MASTER is locked. Under modular U-shape cells, this relation becomes completely fluid, letting operator tablets dynamically report telemetry regardless of local physical machine transfers.

Business Requirements Document

Apparel Manufacturing Execution System Layout Configurator

Hierarchical Structure

An apparel MES organizes the factory floor using a strict top-down layout to ensure accurate tracking of production progress, efficiency, and bottleneck detection:

  • Line Groups: Collections of production lines representing distinct divisions (e.g., woven wear vs. knitwear departments).
  • Lines: Specific sequences of workstations dedicated to completing a garment style. Layout configuration changes based on operational flows.
  • Machines / Workstations: Individual physical equipment units (e.g., lockstitch, overlock, buttonhole sewing systems) mapped to sequential points of production.

Configuration Workflow by Layout Type

1. Traditional Assembly Line Setup

  • Sequential fixed layouts matching sewing routing workflows.
  • Fixed station mappings with one-to-one assigned machinery.
  • Fixed tablet hardware mounted permanently per location.
  • Tapped count triggers automated "+1" completions matching bundle identifiers.

2. Modular / Cell-Based Layout Setup

  • U-shaped or circular configurations utilizing fluid stations.
  • Dynamic machinery mapping with operator multi-handling.
  • Floating Tablet setup models linked to traveling operators, or Shared Cell Hubs.
  • Optimized touch UI enabling rapid user and station context changes.

Tablet UI Design for Manual Data Collection

In-house manual entry tablets require optimized UI constraints to prevent error propagation:

  • Biometric or QR Code Login: Eliminates slow typing. Supported through simulate RFID badge logins.
  • Visual Operation Selection: Icons and part diagrams used in place of text-heavy operational codes.
  • Large Touch Targets: Dedicated high-contrast "GOOD PIECE (+1)" and "REWORK" action buttons.
  • Real-time Feedback Loop: Live output vs hourly targets displayed in direct high-contrast performance gauges.
System User Manual & SOP

POC Web App User Manual

Interactive Guide & Walkthrough

Welcome to the ApparelThread Manufacturing Execution System POC. Follow these steps to experience the complete configuration and data tracking lifecycle:

1

Explore the Digital Blueprint

Navigate to the Floor Dashboard. The Interactive Tree automatically details your existing hierarchy of Line Groups, Lines, Workstations, and Machines. This dynamic mapping links every level together.

2

Register Machinery & Line Setups

Use the configuration tabs (Line Groups, Production Lines, Workstations, Machine Registry) to create, edit, or modify factory assets. You can define layout structures (Traditional vs. Modular Cell), SAM efficiency benchmarks, and target hardware.

3

Simulate Floor Production Actions

Open the **Tablet Simulator**. Select a workstation from the dropdown menu. Tap on any operator badge to log in instantly. Switch garment assembly operations, and click **GOOD PIECE** or **REWORK** to simulate live factory floor activities.

4

Verify Live Data Propagation

Return to the Floor Dashboard. Notice how the total simulated runs, production activity logs, and real-time efficiency percentages automatically sync and reflect the simulator inputs instantly.

Testing Reset Strategy

Should you wish to reload original system defaults, utilize the **"Reset Factory Data"** action located inside the bottom side menu block. This clears your local storage state and re-injects demo assets.
